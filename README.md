# PLP Python Week 3 Assignment

This repository contains two Python programs.

## Files

1. grade_reporter.py
- Reads student marks and assigns grades (A-F)
- Calculates average, highest and lowest marks
- Finds passed and failed students

2. bug_hunt.py
- Fixed version of a buggy counting program
- Calculates sum of numbers from 1 to 5 (total = 15)

## How to Run

py grade_reporter.py
py bug_hunt.py
